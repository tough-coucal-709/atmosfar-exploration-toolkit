# ATMOSFAR Exploration Toolkit — feature reference

ATMOSFAR Exploration Toolkit brings journey notes and equipment groups into one section-based interface. Session records provides the third part of the workflow.

| Section | Description |
|---|---|
| Journey notes | Route stages, transport context, and the notes associated with each part of the journey. |
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
